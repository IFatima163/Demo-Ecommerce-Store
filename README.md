# Demo Ecommerce Store
A demo version of the potential structure, layout, and animations that can be used to build an ecommerce store from services and product portfolio to team members and their expertise.

## Features
- portfolio of previous projects
- team member introductions and their expertise
- showcase of services
- contact form for easy communication
- quota option for custom projects

## Tech Stack
- **Frontend:** React, Vite, Lucide
- **Styling:** CSS
- **Deployment:** GitHub Pages
